# Final public evidence

`generated/` is produced by `python -m scripts.build_final_artifacts`. It contains final figures, compact headline tables, a 363-record successful-run ledger, an incident ledger, compute disclosures, hashes, and the Week 10 completion summary.

All inputs are tracked Week 8 and Week 9 aggregate artifacts. The directory excludes evaluation labels, logits, checkpoints, weights, cached patch features, and patch-level neighbour or sensitivity records.
